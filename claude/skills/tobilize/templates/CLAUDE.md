# CLAUDE.md

CLAUDE.md contains instructions for how Claude Code should approach work in this codebase.

@README.md contains the high-level project description, mainly aimed at human consumption.

@docs/approach.md describes how to work in this codebase: where documentation lives, when to update it, and how the assistant and the docs tree stay in sync.

The `docs/` directory contains durable documentation about the project. Each subdirectory has an `INDEX.md` — start there. Add to existing files when you learn something durable; create new files when you have enough material to justify it.
